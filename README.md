# Intrinsic

**An investment research and financial analysis platform.**

[**Launch Intrinsic →**](intrinsic-production.up.railway.app)

## Overview

Intrinsic is a full-stack investment research platform that brings company financials, quantitative analysis, and discounted cash flow valuation into one interface. It helps investors assess business performance, estimate intrinsic value under different scenarios, and track how their investment theses evolve over time.

## Features

- **Company analysis:** Retrieve and explore financial data from publicly traded companies.
- **Quantitative analysis:** Evaluate companies using financial metrics and historical performance.
- **DCF valuation:** Estimate intrinsic value using customizable assumptions and bear, base, and bull scenarios.
- **Watchlist:** Save companies and access their analyses.
- **Analysis history:** Save multiple versions of an analysis and revisit previous valuations.
- **Comparison:** Compare company analyses and historical valuations.
- **Authentication:** Personal accounts with individually scoped watchlists and saved analyses.
